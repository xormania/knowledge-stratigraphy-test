# Code of Conduct

Everyone is welcome to participate, regardless of experience, background, identity, or
choice of development tools. Be respectful, specific, and willing to revise a claim
when evidence changes. Criticize code and reasoning, not people.

Harassment, threats, discrimination, sexualized conduct, doxxing, unsolicited promotion,
impersonation, fabricated evidence, and repetitive spam are not acceptable. Technical
disagreement, honest mistakes, and asking for help are not misconduct. Do not use the
contribution policy to belittle new contributors.

## Scope and enforcement

These standards apply to the project's issues, PRs, discussions, reviews, and official
representation. The maintainer, `@xormania`, may request corrections, remove harmful
content, close spam, restrict interactions, or block repeat abusers. Responses should
be proportionate; a rejected patch is not a judgment about its author.

For an ordinary concern, contact `@xormania` in the relevant GitHub thread. For sensitive
harassment or personal information, use GitHub's **Report abuse** mechanism rather than
posting details publicly. This project does not currently publish a private conduct
mailbox; do not assume GitHub issues are confidential. Security vulnerabilities follow
[SECURITY.md](SECURITY.md) instead.

Explain moderation decisions when doing so is safe, allow good-faith corrections, and
respect the privacy of affected people. There is no promise of an immediate response.
